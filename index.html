Code

  • WorkpaperDiff - compares two Excel workpapers for accounting logic changes: formulas replaced by values, sign flips, stale dates, and broken prior-period links.
  • ClaimBench - provides synthetic claim-to-cash scenarios with authoritative expected journal entries and subledger states for testing revenue-cycle accounting without patient data.
  • RateTest - runs executable tests for payer-contract math, with expected amounts shown step by step from case rates to stop-loss scenarios.
  • TieOut - expresses reconciliations and rollforwards as executable JSON specifications with decimal arithmetic, CSV selectors, and a nonzero exit on failed checks.
  • HCRIS Kit - loads CMS hospital cost-report extracts into SQLite without losing worksheet coordinates, preserving each value's source row.
  • Go for a Drive - a real-time pixel coastline with a wandering road, setting sun, dashboard clock, and streaming radio.

Colophon

Hand-written HTML - no framework, no build step, no analytics, no cookies. View source and you've seen the whole thing. Text is set in Charter with monospace labels; both ship with your operating system, so nothing downloads.

The drive is its own page: a pseudo-3D coastline drawn on a ~320×180 canvas at 60 frames a second, upscaled with hard pixels. The road bends on a random walk, the sun sets in real time, and the dash clock keeps your time. The radio streams two and a quarter hours of K-Billy's Super Sounds of the 70's in range requests - you download only what you listen to. It respects reduced-motion settings.

Built at a terminal with Claude Code riding shotgun. Hosted on Cloudflare Pages.
