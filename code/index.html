Software · data tools · interactive projects

Applications

  • Paperwork PDF Reader & Editor - an early, local-first PDF workstation for reading, selecting, searching, annotating, signing, running OCR, combining documents, organizing pages, and exporting edited copies. Version 0.1.5 makes native and exported sticky notes visible, editable, searchable, and printable, while improving multiline text, annotation validation, and backup integrity. Documents remain on your computer. It is now packaged as a real desktop application—no Node.js or command window required. Download the macOS app or Windows installer. The apps are not yet notarized or code-signed, so macOS Gatekeeper or Windows SmartScreen may ask you to confirm the first launch. Source code and SHA-256 checksums are also available.
  • Personal ERP - local-first household accounting with a double-entry ledger, reconciliation, financial statements, budgets, forecasts, fixed assets, and debt schedules.
  • PlusFive - an offline, phone-first training log for the Starting Strength novice progression. It installs from the browser and stores workout data on the device.
  • F1 Pit Wall - live Formula 1 timing and strategy, a 14-tool analysis lab, and a new project-based analytics studio for configurable reports, cross-filtering, reusable templates, and session-data exports.

Accounting & data

  • ClearRate - turns hospital price-transparency files into queryable data. The public MRF Reader inspects large published files without loading them entirely into memory.
  • WorkpaperDiff - compares two Excel workpapers for accounting logic changes: formulas replaced by values, sign flips, stale dates, and broken prior-period links.
  • ClaimBench - provides synthetic claim-to-cash scenarios with authoritative expected journal entries and subledger states for testing revenue-cycle accounting without patient data.
  • RateTest - runs executable tests for payer-contract math, with expected amounts shown step by step from case rates to stop-loss scenarios.
  • TieOut - expresses reconciliations and rollforwards as executable JSON specifications with decimal arithmetic, CSV selectors, and a nonzero exit on failed checks.
  • HCRIS Kit - loads CMS hospital cost-report extracts into SQLite without losing worksheet coordinates, preserving each value's source row.
