Race-day automatic

This page reads the calendar, recognizes the current Grand Prix, and switches from the Monaco replay to public live timing. Leave it open: the tower refreshes throughout the race.

Transparent model

The rejoin number is simple arithmetic: gap to the leader plus an adjustable pit-loss assumption, ranked back into the field. The calculation updates with every timing refresh.

# run your own live wall; standard library only
python3 pitwall.py serve --session latest

# adjust the circuit's pit-loss assumption
python3 pitwall.py serve --pit-loss 22
